# Recruit Sender

Extensão para Google Chrome que permite enviar mensagens personalizadas em massa pelo WhatsApp Web.

Desenvolvida principalmente para recrutadores e profissionais de RH, facilita o contato com candidatos em processos seletivos.

**Funcionalidades:**

- Envio de mensagens para múltiplos contatos.

- Personalização automática com o nome do destinatário.

- Importação de contatos por copiar e colar dados de tabelas (nome e telefone).

- Agilidade na comunicação com candidatos.

Tecnologias

Projeto desenvolvido com apoio do Lovable, com código-fonte versionado no GitHub.
[Lovable](https://lovable.dev).

**Baixe aqui**: https://send-joy-whisper.lovable.app

## Desenvolvimento local

Prefere trabalhar localmente? Você precisa do Node.js e do npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Uso responsável

Utilize a extensão respeitando a privacidade dos contatos, a LGPD e os termos de uso do WhatsApp.
